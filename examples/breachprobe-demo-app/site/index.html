Notes that sync between your devices

demo-app is a demo notes app. You write a note on your laptop and it is on your phone a second later. Every note is stored in a hosted database, and the app reads and writes it from the browser with the database's public key.

This site is the worked example from BreachProbe, rebuilt as a local fixture. It carries the same defects the BreachProbe sample report finds: database tables anyone can read, a missing Content-Security-Policy and Referrer-Policy, an admin check in the browser, and a session token kept in localStorage.
